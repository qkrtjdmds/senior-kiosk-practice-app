# 한걸음 디지털

한걸음 디지털은 어르신이 키오스크와 스마트폰 사용법을 큰 글씨와 쉬운 안내로 천천히 연습할 수 있는 Flutter Android 앱입니다. 로그인이나 서버 연결 없이 기기 안에서 동작하며, 실제 주문·결제·금융 거래·서류 발급은 수행하지 않습니다.

## 주요 기능

### 7가지 생활 연습

- 카페 키오스크 주문
- 병원 접수
- 사진 보내기
- 기차표 예매 V2
- 햄버거 주문
- ATM 출금
- 무인민원발급기 서류 발급

각 콘텐츠는 안내를 따라 진행하는 `따라 해보기`와 목표를 기억하고 직접 선택하는 `혼자 해보기`를 제공합니다.

### 카페 키오스크 V2

- 카테고리별 2열 가상 메뉴판
- 온도, 크기, 매장·포장 선택
- 여러 메뉴를 담을 수 있는 장바구니와 수량 조절
- 실제 정보 입력이나 연동이 없는 포인트 적립 연습
- 실제 결제가 진행되지 않는 결제 수단 선택 연습
- 선택 내용을 정리한 영수증형 완료 화면
- 따라 해보기 안내와 혼자 해보기 인라인 힌트
- 작은 화면과 큰 글씨 설정을 고려한 반응형 UI

기존 카페 V1 코드는 유지되며, 앱의 카페 진입 경로는 V2 화면으로 연결됩니다.

### 햄버거 주문 V2

- 매장·포장과 2열 가상 메뉴판
- 단품·세트 분기와 사이드·음료 선택
- 추가·제외 옵션, 복수 메뉴 장바구니, 수량·합계 계산
- 실제 개인정보 입력이나 연동이 없는 포인트 적립 연습
- 실제 결제가 진행되지 않는 결제 수단 선택 연습
- 주문 내용을 정리한 영수증형 완료 화면
- 따라 해보기와 기존 3개 혼자 해보기 미션
- 오늘의 랜덤 미션, 포인트·배지·최근 기록 연동

### 병원 무인 접수 V2

- 진료 접수, 방문 이력, 예약 여부, 진료과와 방문 이유를 차례로 선택하는 가상 접수 흐름
- 가상 환자 확인 뒤 연습용 예약 3개 중 목표 예약을 찾는 예약 확인 흐름
- 미납 가상 진료비 선택, 카드·간편결제·현금 안내와 영수증을 연습하는 진료비 수납 흐름
- 실제 개인정보를 저장하지 않는 연습용 환자 확인 숫자 키패드
- 따라 해보기 안내와 세 가지 혼자 해보기 미션
- 접수 내용 확인과 연습용 대기 번호 완료 화면
- 업무별 포인트·완료 횟수·최근 기록과 세션별 중복 지급 방지
- 기존 오늘의 랜덤 미션은 진료 접수 혼자 해보기에만 연동
- 통원확인서 등 가상 서류 선택, 제출 용도·부수·수수료 확인, 가상 결제·출력·서류 챙기기 연습

기존 병원 V1 소스는 유지되며, 앱의 병원 진입 경로는 V2 화면으로 연결됩니다.
### 기차표 예매 V2

- 편도·왕복과 출발역·도착역 검색 및 서로 바꾸기
- 한국 날짜 기준 달력, 시간대와 성인·어린이·경로 승객 선택
- 가상 열차 조회, 일반실·우등실 운임과 좌석도
- 예매 확인, 카드·간편결제 연습과 연습용 모바일 승차권
- 따라 해보기와 세 가지 혼자 해보기 시나리오
- 기존 포인트·배지·최근 기록 및 오늘의 랜덤 미션 연동

실제 철도 시간표, 예약, 결제, QR과 연결되지 않으며 모든 데이터는 연습용입니다.

### 오늘의 랜덤 미션

- 한국 날짜(UTC+9)를 기준으로 매일 서로 다른 콘텐츠 미션 3개 선정
- 같은 날짜에는 앱을 다시 실행해도 동일한 미션 유지
- 전날과 완전히 같은 미션 조합 방지
- 미션 탭에서 시작한 혼자 해보기를 정상 완료했을 때만 완료로 인정
- 기존 혼자 해보기 보상 20점과 오늘의 미션 추가 보상 10점 지급
- 날짜와 미션별 추가 보상 중복 지급 방지
- 홈과 미션 탭의 `N / 3 완료` 진행 상태 연동

### 학습 기록과 접근성

- 포인트, 콘텐츠별 완료 횟수, 첫 완료 배지
- 최근 연습 기록
- SharedPreferences를 이용한 기기 내 저장과 앱 재실행 후 복원
- 완료 화면 재진입과 빠른 반복 요청에 대한 보상 중복 지급 방지
- 글씨 크기: 보통, 크게, 아주 크게
- 화면 대비: 편안한 화면, 선명한 화면
- 확인 절차가 있는 연습 기록 초기화
- 홈, 연습, 미션, 내 정보 하단 탭

## 실행 방법

Flutter SDK와 Android 개발 환경을 준비한 뒤 프로젝트 루트에서 실행합니다.


## 연습 진입 방식

- 홈: 7개 콘텐츠의 자유 연습을 바로 시작하며 포인트·완료 횟수·배지 보상은 없습니다.
- 연습하기: 기존 따라 해보기(+10점)와 혼자 해보기(+20점)를 선택합니다.
- 미션: 한국 날짜 기준 오늘의 미션 3개에서 혼자 해보기를 완료하면 기존 보상과 추가 10점을 받습니다.
- 내 정보: 포인트, 완료 횟수, 배지, 최근 기록, 화면 설정과 기록 초기화를 확인합니다.

자유 연습은 기존 보상 데이터와의 호환성을 위해 포인트·완료 횟수·배지뿐 아니라 최근 연습 기록에도 저장하지 않습니다.

자세한 정책은 [연습 진입 구조](docs/연습_진입_구조.md)에서 확인할 수 있습니다.

## 범위와 향후 계획

현재 앱은 학습용 가상 화면만 제공하며 실제 서비스, 실제 주문·예약·결제·사진 전송, 계정, 서버, Firebase, 구독, 푸시 알림과 연결되지 않습니다. 핵심 학습 콘텐츠 7종의 V2 전환과 자유 연습 진입 구조를 완료했으며 다음 작업은 캐릭터 중심 전체 디자인 리뉴얼입니다.

## ATM 출금 V2

- 실제 금융 거래 없이 카드 넣기, 연습용 PIN, 가상 계좌와 금액 선택을 연습
- 금액·가상 수수료 확인 후 카드와 현금을 순서대로 챙기는 안전 교육
- 따라 해보기와 3가지 혼자 해보기 미션, 오늘의 랜덤 미션 연동
- 기존 ATM 포인트·완료 횟수·첫 완료 배지·최근 기록 저장 방식 유지
- 실제 카드, 계좌번호, 비밀번호 저장, 은행 API 및 출금 기능은 사용하지 않음

자세한 구현 원칙은 [ATM 출금 V2 설계](docs/ATM_출금_V2_설계.md)에서 확인할 수 있습니다.

Small Phone 에뮬레이터에서 360dp 기본 글씨와 320dp 아주 큰 글씨 조건의 주요 흐름, PIN 비저장, 카드·현금 회수 순서, Android 뒤로가기를 확인했습니다.

다음 예정 작업은 캐릭터 중심의 전체 앱 디자인 시스템과 홈·미션·내 정보 화면 리디자인입니다.

## 무인민원발급기 V2

- 주민등록표 등본·초본, 가족관계증명서, 기본증명서, 건축물대장, 지방세 세목별 과세증명 등 연습 증명서 6종
- 실제 현장 적응을 위한 증명서 분야·서류·옵션·부수 선택 연습
- 실제 개인정보와 지문을 받지 않는 가상 본인 확인·지문 재시도
- 교육용 가상 수수료와 카드·현금 결제, 카드·잔돈 회수 순서
- 실제 문서나 프린터를 사용하지 않는 가상 출력과 증명서 회수·안전 종료
- 따라 해보기와 세 가지 혼자 해보기, 기존 오늘의 랜덤 미션·포인트·배지·최근 기록 연동

실제 기기마다 발급 서류, 화면, 수수료와 결제 지원 방식이 다를 수 있습니다. 실제 행정기관 신청, 개인정보 저장, 생체정보 수집, 결제와 문서 출력은 이루어지지 않습니다.

Small_Phone Android 15(API 35)에서 360dp 기본 글씨의 따라 하기 전체 흐름과 혼자 하기 카드·현금 시나리오를 완료했습니다. 320dp·아주 큰 글씨에서도 옵션 5종, 고정 하단 버튼과 세로 스크롤을 확인했으며 카드·잔돈·증명서 회수 순서와 시스템 뒤로가기 차단을 검증했습니다.

## 사진 보내기 V2

- 가상 연락처와 도형 기반 연습 사진만 사용하는 안전한 메신저 연습
- 사진 접근 범위 교육과 실제 권한을 요청하지 않는 선택 화면
- 최대 3장 선택, 선택 취소·순서 표시·크게 보기·미리보기
- 받는 사람과 개인·단체 채팅 여부를 전송 전에 다시 확인
- 네트워크·파일 업로드·외부 공유가 없는 가상 전송과 잘못 보냈을 때 대처 교육
- 따라 해보기와 혼자 해보기 3종, 기존 포인트·배지·최근 기록·오늘의 랜덤 미션 연동

실제 연락처, 전화번호, 갤러리, 카메라, 메신저, 사진 파일과 위치정보를 읽거나 저장하지 않습니다. 실제 사진은 전송되지 않으며 메신저별 권한과 삭제 방식은 다를 수 있습니다.

Small Phone Android 15(API 35)에서 360dp 따라 해보기 전체 흐름과 혼자 해보기 첫 시나리오를 완료했습니다. 320dp·아주 큰 글씨 조건에서는 시작 화면과 연락처 목록을 확인하고, 위젯 테스트로 2열 사진 선택 화면과 오버플로우 방지를 검증했습니다.

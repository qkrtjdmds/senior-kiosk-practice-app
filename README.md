# 한걸음 디지털

한걸음 디지털은 어르신이 키오스크와 스마트폰 사용법을 큰 글씨와 쉬운 안내로 천천히 연습할 수 있는 Flutter Android 앱입니다. 로그인이나 서버 연결 없이 기기 안에서 동작하며, 실제 주문·결제·금융 거래·서류 발급은 수행하지 않습니다.

## 주요 기능

### 7가지 생활 연습

- 카페 키오스크 주문
- 병원 접수
- 사진 보내기
- KTX 기차표 예매
- 햄버거 주문
- ATM 출금
- 무인민원발급기 서류 발급

각 콘텐츠는 안내를 따라 진행하는 `따라 해보기`와 목표를 기억하고 직접 선택하는 `혼자 해보기`를 제공합니다.

### 카페 키오스크 V2

- 카테고리별 2열 가상 메뉴판
- 온도, 크기, 매장·포장 선택
- 여러 메뉴를 담을 수 있는 장바구니와 수량 조절
- 실제 정보 입력이나 연동이 없는 포인트 적립 연습
- 실제 결제가 진행되지 않는 결제 수단 선택 연습
- 선택 내용을 정리한 영수증형 완료 화면
- 따라 해보기 안내와 혼자 해보기 인라인 힌트
- 작은 화면과 큰 글씨 설정을 고려한 반응형 UI

기존 카페 V1 코드는 유지되며, 앱의 카페 진입 경로는 V2 화면으로 연결됩니다.

### 오늘의 랜덤 미션

- 한국 날짜(UTC+9)를 기준으로 매일 서로 다른 콘텐츠 미션 3개 선정
- 같은 날짜에는 앱을 다시 실행해도 동일한 미션 유지
- 전날과 완전히 같은 미션 조합 방지
- 미션 탭에서 시작한 혼자 해보기를 정상 완료했을 때만 완료로 인정
- 기존 혼자 해보기 보상 20점과 오늘의 미션 추가 보상 10점 지급
- 날짜와 미션별 추가 보상 중복 지급 방지
- 홈과 미션 탭의 `N / 3 완료` 진행 상태 연동

### 학습 기록과 접근성

- 포인트, 콘텐츠별 완료 횟수, 첫 완료 배지
- 최근 연습 기록
- SharedPreferences를 이용한 기기 내 저장과 앱 재실행 후 복원
- 완료 화면 재진입과 빠른 반복 요청에 대한 보상 중복 지급 방지
- 글씨 크기: 보통, 크게, 아주 크게
- 화면 대비: 편안한 화면, 선명한 화면
- 확인 절차가 있는 연습 기록 초기화
- 홈, 연습, 미션, 내 정보 하단 탭

## 실행 방법

Flutter SDK와 Android 개발 환경을 준비한 뒤 프로젝트 루트에서 실행합니다.

```bash
flutter pub get
flutter run
```

실행 전에 Android Studio에서 에뮬레이터를 시작하거나 Android 기기를 연결합니다.

## 테스트와 빌드

```bash
dart format lib test
flutter analyze
flutter test
flutter build apk --debug
```

# 한걸음 디지털

한걸음 디지털은 어르신이 키오스크와 스마트폰 사용법을 큰 글씨와 쉬운 안내로 천천히 연습할 수 있는 Flutter Android 앱입니다.

V1은 로그인이나 서버 연결 없이 기기 안에서 동작하는 연습용 앱입니다. 실제 주문, 결제, 금융 거래, 서류 발급은 수행하지 않습니다.

## 주요 기능

### 생활 디지털 연습

- 카페 키오스크 주문 연습
- 병원 접수 연습
- 사진 보내기 연습
- 기차표 예매 연습
- 햄버거 주문 연습
- ATM 출금 연습
- 무인민원발급기 서류 발급 연습

각 학습은 안내를 보며 순서대로 진행하는 **따라 해보기**와 목표를 기억하고 직접 선택하는 **혼자 해보기 미션**을 제공합니다.

### 학습 기록

- 따라 해보기 완료 시 포인트 적립
- 혼자 해보기 완료 시 포인트와 첫 완료 배지 적립
- 콘텐츠별 완료 횟수 표시
- 최근 연습 기록 표시
- 완료 화면 재진입, 반복 클릭, 앱 재시작 후에도 완료 보상이 중복 지급되지 않도록 보호
- 포인트, 완료 횟수, 배지, 최근 기록을 SharedPreferences에 로컬 저장

### 접근성 및 설정

- 글자 크기: 보통, 크게, 아주 크게
- 화면 대비: 편안한 화면, 선명한 화면
- 설정값을 앱 재시작 후에도 유지
- 확인 창을 거친 연습 기록 초기화
- 기록을 초기화해도 글자 크기와 화면 대비 설정은 유지
- 홈, 연습, 미션, 내 정보 하단 탭 제공

## 기술 스택

- Flutter / Dart
- Material 3
- provider
- go_router
- shared_preferences
- Android 우선

## 실행 방법

Flutter SDK와 Android 개발 환경을 준비한 뒤 프로젝트 루트에서 실행합니다.

```bash
flutter pub get
flutter run
```

Android에서 확인하려면 `flutter run` 전에 Android Studio에서 에뮬레이터를 실행하거나 Android 기기를 연결합니다.

## 검증

```bash
flutter analyze
flutter test
```

테스트는 주요 화면 이동, 학습 완료 흐름, 포인트·배지·최근 기록 저장, 중복 보상 방지, 설정 복원, 기록 초기화, 좁은 화면과 큰 글씨에서의 레이아웃을 확인합니다.

## 프로젝트 구조

```text
lib/
  app/                 # 앱 테마와 go_router 설정
  features/
    atm/               # ATM 출금 연습
    civil_document/    # 무인민원발급기 연습
    hamburger/         # 햄버거 주문 연습
    home/              # 홈 화면
    hospital/          # 병원 접수 연습
    learning/          # 카페 학습, 학습 기록 Provider, 공통 학습 UI
    photo/             # 사진 보내기 연습
    progress/          # 포인트, 배지, 완료 및 최근 기록
    settings/          # 글자 크기, 화면 대비, 기록 초기화
    tabs/              # 홈, 연습, 미션, 내 정보 하단 탭
    train/             # 기차표 예매 연습
  shared/              # 공통 화면 위젯
test/                  # 기능, 저장, 라우팅, 접근성 테스트
```

## V1 범위

- 실제 브랜드, 은행, 정부기관 화면을 복제하지 않은 가상 연습 화면
- 실제 결제, 금융 거래, 개인정보 입력 또는 외부 서비스 연결 없음
- Firebase, 로그인, 서버, 데이터베이스, 광고, 구독 기능 없음

## 앞으로 할 일

- 실제 키오스크와 유사한 UI와 상호작용 강화
- 단계별 피드백과 학습 통계 고도화
- 필요한 경우 서버 및 계정 연동 검토
- 어르신 대상 사용성 테스트와 접근성 개선

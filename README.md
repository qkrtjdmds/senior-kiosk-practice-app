# 한걸음 디지털

키오스크와 디지털 기기 사용이 낯선 어르신이 생활 속 상황을 큰 글씨와 쉬운 안내로 단계별 연습하는 Flutter 앱입니다.

## 현재 구현 기능

- 홈·연습·미션·내 정보로 구성된 4개 하단 탭
- 카페 주문, 병원 접수, 사진 보내기, KTX 기차표 예매 학습
- 햄버거 주문, ATM 출금, 무인민원발급기 학습
- 각 학습의 안내 중심 `따라 해보기`와 목표를 기억하는 `혼자 해보기` 미션
- 따라 해보기 완료 시 10점, 혼자 해보기 완료 시 20점 지급
- 콘텐츠별 따라 하기·혼자 하기 완료 횟수와 첫 완료 배지
- 최근 연습 활동 기록과 최대 20개 로컬 보관
- SharedPreferences 기반의 포인트·기록·배지 로컬 저장
- 세션별 보상 지급 상태를 함께 저장해 완료 화면 재진입, 연속 클릭, 앱 재시작 뒤에도 보상이 중복 지급되지 않도록 보호
- 글씨 크기와 화면 대비 설정 및 연습 기록 초기화
- 카페·햄버거·ATM에 적용된 공통 학습 UI와 좁은 화면 대응
- 큰 글씨·넓은 버튼·쉬운 한국어 안내 중심의 반응형 Material 3 UI

## 프로젝트 구조

```text
lib/
	app/                    # Material 3 테마와 go_router 설정
	features/
		atm/                  # ATM 출금 학습
		civil_document/       # 무인민원발급기 학습
		home/                 # 홈 화면
		hamburger/            # 햄버거 주문 학습
		hospital/             # 병원 접수 학습
		learning/             # 카페 학습과 공통 학습 위젯/provider
		photo/                # 사진 보내기 학습
		progress/             # 나의 디지털 걸음과 최근 기록
		settings/             # 글씨 크기·화면 대비·기록 관리
		tabs/                 # 홈·연습·미션·내 정보 하단 탭
		train/                # 기차표 예매 학습
	shared/                 # 공통 화면 구성 요소
test/                     # 위젯 및 학습 흐름 테스트
```

## UX 방향

어르신이 편안하게 사용할 수 있도록 큰 글씨와 큰 버튼, 밝은 색상, 충분한 여백, 쉬운 한국어 안내를 중심으로 구성했습니다.

## 기술 스택

- Flutter / Dart / Material 3
- Provider
- go_router
- SharedPreferences

## 실행 방법

1. 의존성을 설치합니다.

```bash
flutter pub get
```

2. Android Studio에서 Android 에뮬레이터를 실행합니다.
3. 앱을 실행합니다.

```bash
flutter run
```

실행 중에는 다음 명령을 사용할 수 있습니다.

- `r`: Hot Reload
- `R`: Hot Restart
- `q`: 실행 종료

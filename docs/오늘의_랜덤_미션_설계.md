# 오늘의 랜덤 미션 설계

## 기능 목적

매일 세 가지 혼자 해보기 연습을 제안해 반복되는 미션 구성을 줄인다. 일반 학습은 제한 없이 유지하며, 일일 미션으로 시작해 정상 완료한 경우에만 기존 학습 보상에 추가 10점을 지급한다.

## 생성 규칙과 한국 날짜

- 날짜는 기기 시각을 UTC로 변환한 뒤 9시간을 더한 한국 날짜 `yyyy-MM-dd`를 사용한다.
- 저장된 날짜와 오늘이 같으면 저장된 세 미션을 그대로 복원한다.
- 날짜가 바뀌거나 선택 데이터가 손상되면 세 미션을 새로 고른다.
- 한 날에는 미션 ID와 콘텐츠 종류가 중복되지 않는다.
- 전날과 완전히 같은 세 미션 조합은 피한다.
- 선택 횟수가 적은 후보와 전날 포함되지 않은 후보를 우선한다.
- 자동 새로고침이나 수동 재추첨 기능은 제공하지 않는다.

## 후보와 완료 조건

현재 실제 혼자 해보기 완료 경로가 있는 일곱 콘텐츠만 후보로 사용한다.

| 콘텐츠 | 조건 |
| --- | --- |
| 카페 주문 | 카페 V2 혼자 해보기 정상 완료 |
| 햄버거 주문 | 당일 햄버거 혼자 해보기 정상 완료 |
| 병원 접수 | 병원 접수 혼자 해보기 정상 완료 |
| 기차표 예매 | 기차표 예매 혼자 해보기 정상 완료 |
| ATM 출금 | ATM 출금 혼자 해보기 정상 완료 |
| 무인민원발급기 | 서류 발급 혼자 해보기 정상 완료 |
| 사진 보내기 | 사진 보내기 혼자 해보기 정상 완료 |

구현되지 않은 선택 조건은 만들지 않았다. 현재는 각 콘텐츠가 이미 제공하는 고정 또는 자체 선정 미션을 끝까지 완료하는 조건이다.

## 완료 판정

- 미션 카드에서 시작할 때 현재 `missionId`를 세션 상태로 저장한다.
- 해당 콘텐츠의 혼자 해보기 완료 횟수가 실제로 증가한 뒤에만 일일 미션 완료를 요청한다.
- 중간 이탈, 따라 해보기 완료, 다른 콘텐츠 완료는 인정하지 않는다.
- 일반 연습을 새로 시작하면 남아 있던 미션 세션을 해제한다.
- 완료 화면 재진입으로 기존 완료 횟수가 증가하지 않으면 일일 미션도 다시 완료되지 않는다.

## 보상과 중복 방지

- 콘텐츠의 기존 혼자 해보기 보상 20점은 그대로 유지한다.
- 일일 미션은 `한국날짜:미션ID` 보상 토큰으로 추가 10점을 한 번만 지급한다.
- 하루 세 미션의 추가 보상은 최대 30점이다.
- 날짜가 바뀌어도 이전에 지급한 포인트는 취소하지 않는다.
- 완료 상태와 보상 상태를 따로 저장하여 화면 복원과 중복 지급 검사를 분리한다.

## SharedPreferences 구조

- `daily_mission_date`: 오늘 미션의 한국 날짜
- `daily_mission_selected_ids`: 선정된 미션 ID 세 개
- `daily_mission_completed_ids`: 완료한 미션 ID
- `daily_mission_rewarded_ids`: 추가 보상 지급이 확인된 미션 ID
- `daily_mission_completed_at`: 미션별 완료 시각 JSON
- `daily_mission_previous_ids`: 직전 선정 조합
- `daily_mission_frequency`: 후보별 누적 선정 횟수 JSON
- `daily_mission_active_id`: 미션 화면에서 시작한 현재 세션
- `daily_mission_reward_tokens`: 이미 지급한 `날짜:미션ID` 토큰

잘못된 ID, 중복 ID, 세 개가 아닌 선택 목록은 손상 데이터로 보고 오늘 미션을 다시 생성한다. 보상 토큰은 별도 키로 남아 같은 날짜와 미션에 대한 재지급을 막는다.

연습 기록 초기화는 위 미션 데이터와 보상 토큰을 함께 초기화한다. 글자 크기와 화면 대비 설정은 기존 정책대로 유지한다.

## 화면 연결

- 홈에는 `오늘의 미션 N/3`, 진행 바, 미션 탭 이동 링크만 작게 표시한다.
- 미션 탭에는 날짜, 전체 진행률, 오늘 선정된 세 항목을 표시한다.
- 완료 항목은 체크 표시와 차분한 배경을 사용하며 다시 연습할 수 있지만 추가 보상은 지급하지 않는다.
- 알림은 검은 Snackbar나 팝업 대신 화면 안 인라인 메시지로 표시한다.
- 상세 학습 화면은 기존 라우트와 혼자 해보기 UI를 그대로 재사용한다.

## 현재 한계와 확장 방향

현재 각 콘텐츠의 세부 주문 조건이 모두 공통 상태 모델로 노출되어 있지는 않으므로, 존재하지 않는 옵션을 임의로 조건화하지 않았다. 향후 각 V2 콘텐츠가 조건별 결과 모델을 제공하면 같은 `MissionDefinition.conditionId`를 확장해 한 콘텐츠 안에서도 여러 조건 미션을 안전하게 선정할 수 있다.

## 검증 항목

- 같은 한국 날짜의 선정 결과 유지와 날짜 변경 생성
- 세 ID 및 콘텐츠 종류 중복 없음
- 전날과 완전히 같은 조합 회피
- 완료/보상 상태 재실행 복원과 중복 지급 차단
- 일반 학습 보상과 추가 보상의 결합
- 손상 데이터 복구와 기록 초기화 후 접근성 설정 유지
- 홈과 미션 탭 진행 상태 동기화
- 320dp 및 아주 큰 글씨에서 스크롤과 오버플로우 확인

## Android 에뮬레이터 최종 점검

- Small Phone AVD(Android 15, 360dp 상당)에서 기존 앱 데이터를 지우지 않고 실행했다.
- 홈에서 `오늘의 미션 0/3`, 진행 바, `미션 보러 가기`와 고정 하단 탭이 정상 표시됐다.
- 미션 탭에서 서로 다른 콘텐츠 세 개, 한국 날짜, 0/3 진행 상태와 각 추가 보상 안내를 확인했다.
- 미션 카드를 누르면 해당 콘텐츠의 혼자 해보기 안내 화면으로 이동했다.
- 병원 미션 첫 단계에서 뒤로 나간 뒤 SharedPreferences를 확인했을 때 완료 ID와 보상 ID는 비어 있고 포인트도 지급되지 않았다.
- 앱 프로세스를 종료하고 다시 열어도 같은 날짜의 선정 ID와 미완료 상태가 유지됐다.
- 전날 저장된 조합과 다음 한국 날짜의 조합이 달라진 실제 저장값을 확인했다.
- 카드 전체가 눌리는 구조에 `연습 시작하기` 또는 `완료` 문구를 추가해 행동과 상태를 색상 외 정보로도 구분했다.
- 빠른 연속 완료 요청을 막는 메모리 잠금을 보상 Provider와 미션 Provider 양쪽에 추가했다.

## 기록 초기화 정책

`연습 기록 초기화`를 확인하면 포인트, 완료 횟수, 배지, 최근 기록, 일일 미션 선정·완료·보상·활성 세션을 모두 지운다. 초기화 직후 현재 한국 날짜를 기준으로 오늘의 미션 세 개를 새로 생성한다. 글자 크기와 화면 대비 설정은 지우지 않는다.

## 남은 제한 사항

- 미션 조건은 각 콘텐츠가 현재 제공하는 혼자 해보기 정상 완료 단위다. 콘텐츠별 결과 모델이 확장되기 전에는 존재하지 않는 세부 조건을 만들지 않는다.
- 에뮬레이터 실제 점검은 Small Phone 기본 배율을 중심으로 수행하며, 320dp와 아주 큰 글씨 조합은 위젯 회귀 테스트로 함께 검증한다.

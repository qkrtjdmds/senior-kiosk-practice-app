# 무인민원발급기 V2 설계·구현

## 교육 목표와 V1 호환성

주민센터·지하철역·병원 등의 여러 무인민원발급기에서 공통으로 만나는 `서류 선택 → 본인 확인 → 세부 옵션 → 결제 → 출력 → 회수 → 안전 종료` 순서를 안전하게 연습한다. 특정 제조사나 정부 서비스 화면을 복제하지 않는다.

V1 소스는 삭제하지 않고 보존한다. 기존 경로, `civil_document_solo_complete` 미션 ID, SharedPreferences 완료 횟수·배지·세션 키, `completeCivilDocumentLearning()`과 `completeCivilDocumentSoloLearning()`을 재사용한다.

## 최종 화면 흐름

1. 모드 선택과 연습 안내
2. 증명서 분야·서류 선택
3. 발급 가능 여부와 수수료 주의 확인
4. 가상 인물 `김한걸음`의 본인 확인
5. 실제 지문을 수집하지 않는 지문 재시도 연습
6. 개인정보 공개 범위를 포함한 발급 옵션
7. 1~3부와 총 가상 수수료
8. 신청 내용 확인
9. 카드 또는 현금 결제 연습과 카드·잔돈 회수
10. 가상 출력과 증명서 회수
11. 개인정보 안전 종료와 완료 보상

## 연습용 서류와 수수료

- 주민등록표 등본·초본: 200원/부
- 가족관계증명서·기본증명서: 500원/부
- 건축물대장: 500원/부
- 지방세 세목별 과세증명: 800원/부

모든 금액은 정수로 관리하는 교육용 가상 금액이다. 실제 수수료와 발급 가능 여부는 설치 장소·지역·서류·감면 여부에 따라 다를 수 있다.

## 개인정보·지문 보호

- 주민등록번호·실제 주소·신분증·휴대전화·카드번호를 받지 않는다.
- 실제 지문·생체정보 API를 사용하지 않고 Flutter 기본 아이콘과 상태만 사용한다.
- 가상 미리보기에는 `******-*******`만 표시한다.
- 본인 확인·지문·결제·출력은 Provider 메모리의 임시 상태며 완료·이탈·재시작 시 제거한다.

## 따라 해보기·혼자 해보기

따라 해보기는 등본, 뒷자리 비공개, 1부, 카드 결제를 안내한다. 지문 첫 시도는 부드러운 재시도 안내를 경험한다.

혼자 해보기는 완료 횟수에 따라 등본 1부 카드, 초본 2부 현금, 가족관계증명서 1부 카드 시나리오를 순환한다. 정답을 미리 강조하지 않고 인라인 힌트를 요청할 수 있다.

## 결제·출력·회수 안전

카드는 카드 회수 전, 현금은 잔돈 회수 전에 출력할 수 없다. 가상 출력 완료 전에는 증명서를 챙길 수 없고, 증명서 회수와 개인정보 안전 종료 전에는 완료 보상을 요청할 수 없다. 실제 결제 SDK·NFC·QR·프린터를 사용하지 않는다.

## 보상·일일 미션·초기화

기존 따라 해보기 10점, 혼자 해보기 20점, 일일 미션 10점 추가 보상과 최초 배지를 그대로 사용한다. 미션 탭에서 시작한 `civil_document_solo_complete`만 일일 미션으로 인정하며 중도 이탈 시 활성 ID를 제거한다. 완료 화면은 Provider의 모든 안전 조건을 충족해야 기존 보상 메서드를 호출한다.

새 연습·홈·재시작은 개인정보·지문·결제·출력·회수 임시 상태를 제거한다. 서류·옵션·부수·결제 방법을 변경하면 해당 단계 이후 상태만 초기화한다.

## 접근성과 제한

320dp·아주 큰 글씨에서 세로 스크롤, SafeArea, 56dp 이상 버튼을 사용한다. 상태는 색상 외에 문구·아이콘·테두리로 표시한다. 상단과 Android 뒤로가기는 같은 콜백을 사용한다.

실제 증명서·PDF·이미지·관인·문서번호·QR·바코드를 생성하지 않는다. 법률적 효력이나 제출 적합성을 단정하지 않으며, 실제 기기마다 화면·서류·수수료·결제 지원이 다를 수 있다.

## 구현 구조

- `CivilDocumentV2Provider`: 모드, 시나리오, 서류, 옵션, 부수, 가상 결제, 출력, 회수와 안전 종료 상태를 메모리에서 관리한다.
- `CivilKioskScaffold`: SafeArea, 진행률, 뒤로가기와 하단 주 동작을 일관되게 제공한다.
- `CivilChoiceRow`, `CivilNotice`, `CivilSummary`: 큰 선택 영역, 인라인 안내와 신청·영수증 요약을 재사용한다.
- 기존 무인민원발급기 경로는 V2 화면으로 연결하되 V1 소스와 기존 보상·저장 키는 유지한다.
## 최종 검증 결과

- Small Phone Android 15(API 35), 720×1280·320dpi의 360dp 기본 화면에서 따라 해보기 전체 흐름을 실제 입력으로 완료했다.
- 혼자 해보기는 등본 1부 카드와 초본 2부 현금 시나리오를 실제 완료했다. 가족관계증명서 시나리오와 3개 순환은 Provider 테스트로 확인했다.
- 카드 회수 전 출력, 잔돈 회수 전 출력, 출력 완료 전 증명서 회수와 안전 종료 전 완료가 차단되는 것을 확인했다.
- 출력 단계의 상단·Android 뒤로가기는 같은 인라인 안내를 표시하며 이전 단계 우회를 막는다.
- 640×1280의 320dp 화면과 앱 `아주 크게` 설정에서 시작·분야·지문·옵션 화면을 확인했다. 옵션 5종이 모두 스크롤로 접근됐고 RenderFlex overflow 로그가 없었다.
- 실기에서 따라 해보기의 다른 분야 선택이 다음 단계로 이동하는 문제를 발견했다. 모든 모드에서 현재 시나리오의 분야만 진행하도록 수정하고 회귀 테스트를 추가했다.
- SharedPreferences에는 가상 인물·주소·지문 진행 상태가 저장되지 않았고, 앱 파일에는 PDF·QR·바코드·출력 파일이 생성되지 않았다.
- 검사 후 에뮬레이터 화면 크기는 물리 기본값으로, 앱 글씨 크기는 기존 `보통`으로 복원했다.
- `flutter pub get`, `dart format lib test`, `flutter analyze`, 전체 `flutter test`, `git diff --check`, 디버그 APK 빌드와 `adb install -r`을 최종 통과했다.

실제 기기마다 화면, 발급 항목, 본인 확인 방식, 수수료와 결제 지원은 다를 수 있다. 다음 예정 작업은 `사진 보내기 V2`이다.

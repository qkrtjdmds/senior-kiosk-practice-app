# 내 정보 화면 설계

## 목적

내 정보 화면은 로그인이나 계정 없이 현재 기기에 저장된 연습 성장을 확인하는 곳이다. 프로필을 꾸미는 화면이 아니라 연습 포인트, 완료 횟수, 배지, 최근 활동과 설정을 빠르게 읽고 관리하는 데 집중한다.

## 화면 구조

1. **로컬 기록 안내**
   - 작은 한걸음이와 함께 기록이 이 기기에만 저장된다는 점을 알린다.
   - 로그인과 서버 동기화를 사용하지 않으며 앱 삭제나 기기 변경 시 기록이 사라질 수 있음을 쉬운 문구로 안내한다.
2. **나의 성장 요약**
   - 연습 포인트, 전체 완료 횟수, 획득한 배지 수를 한 영역에서 보여준다.
   - 포인트는 앱 안의 가상 보상임을 명시한다.
3. **콘텐츠별 연습 현황**
   - 카페, 햄버거, 병원, 사진, 기차표, ATM, 서류 발급 순서로 표시한다.
   - 따라 해보기와 혼자 해보기 완료 횟수를 합산하며, 병원은 네 업무의 세부 횟수도 함께 보여준다.
4. **배지**
   - 기존 여덟 개 배지를 모두 표시한다.
   - 획득 여부를 색상만으로 구분하지 않고 아이콘과 `획득` 또는 `아직 획득 전` 문구로 알린다.
5. **최근 활동**
   - 기존 최근 연습 기록을 최신순으로 표시한다.
   - 기록이 없으면 간단한 안내와 `연습하러 가기` 버튼을 제공한다.
6. **설정 및 관리**
   - 현재 글씨 크기와 화면 대비를 보여주고 기존 화면 설정으로 이동한다.
   - 연습 기록 초기화는 내 정보 화면에서 바로 확인 창을 연다.

## 평면형 레이아웃 원칙

- 아이보리 배경, 남색 본문, 세이지 강조라는 기존 디자인 토큰을 사용한다.
- 반복되는 큰 카드를 줄이고, 얇은 테두리 안에서 행과 구분선으로 정보를 묶는다.
- 콘텐츠와 배지는 각각 한 개의 목록 영역으로 구성한다.
- 360dp 보통 글씨에서는 요약 지표를 가로로, 320dp 또는 큰 글씨에서는 세로로 배치한다.
- 모든 내용은 세로 스크롤로 접근할 수 있고 하단 내비게이션에 가리지 않도록 기존 탭 여백을 유지한다.

## 접근성

- 제목은 헤더 Semantics를 제공한다.
- 성장 요약, 콘텐츠 행, 배지, 최근 기록은 각각 한 번에 자연스럽게 읽히도록 하위 장식을 접근성 트리에서 제외한다.
- 터치 동작은 최소 48dp, 주요 버튼은 최소 56dp를 유지한다.
- 획득 여부와 위험 동작은 색상에만 의존하지 않고 한글 문구로 함께 설명한다.
- 기록 초기화 버튼은 확인 창이 열리는 위험 동작임을 Semantics로 알린다.

## 저장과 초기화

화면은 기존 `LearningProgressProvider`의 공개 상태만 읽으며 SharedPreferences 키나 보상 정책을 변경하지 않는다. 초기화 확인 시 기존 `resetPracticeRecords()`를 호출해 포인트, 완료 횟수, 배지, 최근 기록과 미션 기록만 초기화한다. 글씨 크기, 화면 대비와 시작 안내 완료 상태는 유지한다.

자유 연습은 기존 정책대로 포인트, 완료 횟수, 배지와 최근 기록에 포함하지 않는다.

## 개인정보와 향후 계정 기능

현재 버전은 이름, 전화번호, 사진, 위치나 계정 정보를 수집하지 않는다. 서버 동기화도 제공하지 않는다. 향후 계정 기능을 검토할 경우에는 명시적인 동의, 저장 범위, 탈퇴와 데이터 삭제, 기기 간 충돌 처리부터 별도로 설계해야 한다.

## 검증 기준

- 기존 Provider 값으로 성장 요약, 콘텐츠별 완료 현황, 배지와 최근 활동이 표시되는지 확인한다.
- 기록이 없을 때 빈 상태와 연습 이동 버튼이 표시되는지 확인한다.
- 320dp·아주 큰 글씨·선명한 화면에서 모든 항목과 초기화 확인 창을 스크롤로 접근하고 가로 오버플로우가 없는지 확인한다.
- 기록 초기화 직후 화면 값이 갱신되고 접근성 설정과 시작 안내 상태가 유지되는지 확인한다.
- 실제 TalkBack 전수 조작과 제조사별 실기기 검증은 출시 전 남은 확인 항목이다.

## Small Phone 검증 결과

Android 15(API 35) `Small_Phone`에 최신 디버그 APK를 `adb install -r`로 설치해 기존 앱 데이터를 유지했다. 360dp·보통 글씨·편안한 화면과 320dp·아주 큰 글씨·선명한 화면에서 상단 안내, 성장 요약, 콘텐츠 현황, 배지, 최근 활동, 설정과 기록 관리 영역을 끝까지 스크롤해 확인했다.

검증 중 큰 글씨에서 `나의 디지털 걸음`의 마지막 단어가 캐릭터 옆에서 갈라지는 문제를 발견해, 320dp 또는 큰 글씨에서는 캐릭터와 문구를 세로로 배치하도록 수정했다. 기록 초기화 확인 창은 설명과 두 버튼이 잘림 없이 표시되며 `취소`로 닫아 기존 데이터를 보존했다. RenderFlex 오버플로우와 치명적 예외는 발견되지 않았고, 검증 후 화면 크기·글씨 크기·화면 대비를 원래 상태로 복원했다.

APK 재설치 직후 한 차례 `Application does not have a focused window` 시작 창 포커스 타임아웃이 기록됐다. 앱 데이터를 유지한 채 완전 종료 후 콜드 실행, 내 정보 진입과 끝까지 스크롤, 설정 왕복, 백그라운드 복귀를 세 번 반복했으며 추가 ANR은 재현되지 않았다. 세 콜드 실행은 모두 정상 완료됐고 이후 포커스와 화면 전환도 정상이라, 재설치 직후 에뮬레이터 시작 창 전환 문제로 판단한다.

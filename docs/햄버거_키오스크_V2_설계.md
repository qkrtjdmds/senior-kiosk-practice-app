# 햄버거 주문 V2 설계 및 구현 결과

## 목적
어르신이 일반적인 패스트푸드 키오스크 주문 순서를 안전하게 연습하는 가상 화면이다. 실제 브랜드, 주문 전송, 개인정보 입력, 적립 연동, 결제는 사용하지 않는다.

## V1과 달라진 점
- 단순 4단계에서 이용 방법, 메뉴, 단품·세트, 사이드, 음료, 옵션, 장바구니, 적립, 결제, 영수증 흐름으로 확장했다.
- 기존 햄버거 V1 소스와 SharedPreferences 키를 유지했다.
- 기존 `/hamburger` 경로의 구현체만 V2로 연결해 홈·연습·오늘의 미션 링크 호환성을 유지했다.

## 화면 흐름
1. 따라 해보기 또는 혼자 해보기
2. 매장 식사 또는 포장
3. 2열 메뉴판에서 햄버거 선택
4. 단품 또는 세트
5. 세트인 경우 사이드와 음료
6. 추가·제외 옵션 복수 선택
7. 장바구니, 수량 조절, 삭제, 메뉴 추가
8. 포인트 적립 방식
9. 결제 수단
10. 영수증형 완료 화면

단품은 사이드와 음료를 건너뛴다. 빈 장바구니는 주문 확인을 진행할 수 없다.

## 메뉴와 가격
햄버거 6종, 사이드 5종, 음료 6종과 치즈·패티·양상추 추가, 소스·피클 빼기를 제공한다. 모든 금액은 앱 내부에서만 계산되는 연습용 가격이며 세트, 옵션, 수량을 합산한다.

## 상태와 공통 UI
`BurgerOrderProvider`가 모드, 단계, 이용 방법, 메뉴, 단품·세트, 사이드, 음료, 옵션, 장바구니, 수량, 적립, 결제와 인라인 안내를 관리한다. `BurgerCartItem`은 항목별 단가와 합계를 계산한다.

`BurgerKioskScaffold`, `BurgerChoice`, `BurgerMenuTile`, `BurgerInlineNotice`가 낮은 상단 바, 주문 요약, 반응형 메뉴 타일, 선택 UI와 인라인 피드백을 통일한다.

## 따라 해보기와 혼자 해보기
따라 해보기는 고정된 쉬운 주문을 안내하며 다른 선택은 현재 단계에 머문다. 혼자 해보기는 기존 3개 미션 ID를 유지하면서 매장·포장, 메뉴, 단품·세트, 사이드, 음료, 옵션, 적립, 결제 조건을 가진 V2 시나리오로 확장했다. 정답을 미리 강조하지 않고 힌트와 다른 선택 안내를 화면 안에 표시한다.

## 보상과 랜덤 미션
기존 `completeHamburgerLearning()`과 `completeHamburgerSoloLearning()`을 사용하므로 따라 해보기 10점, 혼자 해보기 20점, 완료 횟수, 첫 배지, 최근 기록과 세션 중복 방지 정책이 유지된다. 완료 횟수가 실제 증가했을 때만 `DailyMissionProvider.completeActiveMission()`을 호출해 미션 탭에서 시작한 세션에만 추가 10점을 지급한다.

## 접근성과 제한
- 주요 선택은 최소 76dp이며 아이콘과 한국어를 함께 표시한다.
- 2열 메뉴판은 좁은 화면에서 비율을 조절한다.
- 본문 스크롤, SafeArea 하단 행동 영역, 자연스러운 줄바꿈을 사용한다.
- 실제 주문, 전화번호 입력, 계정 연동, 결제, 서버, Firebase, 로그인, 외부 API는 없다.
- Flutter 기본 아이콘과 색상 영역만 사용한다.

## 최종 에뮬레이터 검증
Android 15(API 35) `Small_Phone` AVD의 `emulator-5554`에서 기존 앱 데이터를 유지한 채 디버그 APK를 설치했다. 약 360dp와 320dp, `아주 크게` 설정에서 시작 화면, 따라 해보기 9단계, 혼자 해보기 목표·인라인 힌트, 장바구니, 적립, 결제, 영수증 완료 화면을 확인했다.

실제 화면에서 발견하고 수정한 항목은 다음과 같다.

- 2열 메뉴에서 큰 글씨가 `치즈버 / 거`처럼 갈라지던 문제를 아이콘·이름·설명·가격의 세로형 `BurgerMenuTile`로 변경했다. 메뉴명과 가격은 한 줄 안에서 안전하게 처리한다.
- 장바구니에 담은 뒤 임시 선택이 비워진 상태에서 이전 버튼이 추가 옵션 화면으로 돌아가던 문제를, 기존 장바구니를 유지한 메뉴판 복귀로 수정했다.
- 세트에서 단품으로 변경하거나 메뉴를 바꿀 때 이전 사이드·음료·옵션이 남지 않도록 하위 선택을 정리한다.
- Android 시스템 뒤로가기도 상단 뒤로가기와 같은 단계 이동을 사용한다.
- 결제 수단은 선택 후 세이지 배경, 진한 테두리, 체크 아이콘을 함께 표시한다.
- 영수증에는 각 메뉴의 단품·세트, 사이드, 음료, 추가·제외 옵션, 수량과 항목 금액을 표시하며 오늘의 미션에서 실제 추가 보상을 받은 경우 10점 안내를 별도로 표시한다.
- 주요 하단 및 완료 버튼의 최소 높이를 56dp로 명시했다.

따라 해보기의 `포장하기 → 불고기버거 → 세트 → 감자튀김 → 콜라 → 옵션 없음 → 적립하지 않기 → 카드` 흐름과 7,700원 합계를 실제 입력으로 완료했다. 불고기버거 5,200원에 세트 2,500원, 치즈 500원, 패티 1,500원을 더한 9,700원과 수량별 합계는 Provider 테스트로 교차 검증했다. 단품은 사이드·음료를 생략하고, 3개 장바구니·중간 삭제·빈 장바구니 차단·메뉴 추가 상태 유지는 회귀 테스트로 검증한다.

혼자 해보기의 세 미션 ID는 유지하며 각 시나리오의 메뉴, 사이드, 음료, 옵션, 적립, 결제 값이 실제 데이터 목록에 존재하는지 테스트한다. 오선택은 현재 단계에 머물고 검은 Snackbar 없이 인라인 안내를 표시한다. 오늘의 랜덤 미션 보상과 재지급 방지, 날짜별 복구는 `DailyMissionProvider` 테스트와 기존 학습 보상 테스트로 확인한다.

## 남은 제한 사항
모든 금액과 결제·적립은 기기 안에서만 동작하는 가상 연습이다. 실제 주문 전송, 개인정보 입력, 결제 승인, 계정 연동은 제공하지 않는다. 메뉴 그림은 실제 브랜드 자산이 아닌 Flutter 기본 아이콘을 사용한다.

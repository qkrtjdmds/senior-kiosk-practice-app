# 출시 전 품질 점검

## 검사 환경

- 기준 커밋: `1443f36d22d86edfae703ec09cdbf37cc65948b1`
- 검사일: 2026-10-07
- Flutter 3.41.5 / Dart 3.11.3
- Windows 개발 환경
- Android Small Phone 에뮬레이터: Android 15(API 35), 360dp 기본 화면
- 반응형 확인: 320dp, 시스템 글씨 배율 1.3, 위젯 테스트 글씨 배율 1.35

## 발견한 문제와 수정 내용

1. `go_router`의 `go`로 연 화면에서 Android 시스템 뒤로가기가 상단 뒤로가기와 다르게 앱을 백그라운드로 보낼 수 있었다.
   - 공통 `PageScaffold`와 햄버거 시작 화면에 안전한 `PopScope` 처리를 추가했다.
   - 이전 화면이 있으면 `pop`, 없으면 지정된 경로 또는 홈으로 이동한다.
2. 진행률과 연습 모드의 접근성 문구가 화면 텍스트와 함께 중복 낭독될 수 있었다.
   - 공통 진행률과 모드 배지 Semantics에서 자식 Semantics를 제외하고 한 번만 명확하게 읽도록 수정했다.
3. 같은 동작의 문구가 `홈으로 가기`, `홈으로 돌아가기`, `혼자 발급해 보기` 등으로 섞여 있었다.
   - 주요 동작을 `홈으로`, `따라 해보기`, `혼자 해보기`, `직원에게 도움 요청`으로 통일했다.
4. 문자열과 라우팅 동작을 확인하는 테스트가 변경된 공통 위젯 구조를 정확히 가리키도록 보완했다.
   - 7개 학습 시작 화면의 Android 시스템 뒤로가기 회귀 테스트를 추가했다.
   - 진행률·모드 Semantics 검증을 추가했다.

## 진입·보상·저장 검증

- 홈: 자유 연습으로 바로 진입하고 보상·완료 횟수·최근 기록·미션 완료에 반영하지 않는다.
- 연습하기: 따라 해보기 10점, 혼자 해보기 20점 정책을 유지한다.
- 오늘의 미션: 지정된 혼자 해보기 완료 시 기본 20점과 추가 10점을 지급하며 추가 보상은 하루 최대 30점이다.
- 내 정보: 포인트, 완료 횟수, 배지, 최근 기록, 설정과 기록 초기화 기능을 유지한다.
- 빠른 중복 요청, 완료 화면 재진입, 앱 재실행, 같은 미션 반복 완료의 중복 보상 방지는 기존 테스트가 통과했다.
- 기록 초기화는 학습 데이터만 초기화하며 글자 크기, 화면 대비, 온보딩 완료 상태는 유지한다.
- 기존 SharedPreferences 키나 저장 모델은 변경하지 않았다.

## 반응형·접근성 결과

- 360dp·보통 글씨와 320dp·아주 큰 글씨·선명한 화면의 공통 UI, 완료 화면, 2열 격자, 키패드와 하단 동작 영역 테스트가 통과했다.
- 주요 버튼 56dp, 아이콘 동작 48dp 이상의 기존 터치 영역을 유지했다.
- 진행률은 단계 문구와 백분율, 모드 배지는 한국어 라벨로 읽히며 중복 낭독을 제거했다.
- ATM·병원 숫자 키와 삭제 버튼, 기차 좌석, 사진 선택 항목의 기존 Semantics 테스트가 통과했다.
- 에뮬레이터에서 320dp·큰 글씨 홈을 직접 확인했고 RenderFlex overflow 및 치명적 예외 로그가 없었다.
- 실제 TalkBack을 활성화한 전수 탐색은 수행하지 못했다. 실제 읽기 순서와 포커스 이동은 실기기에서 추가 확인해야 한다.

## 온보딩과 데이터 보존

- 온보딩 최초 1회 표시, 완료 후 홈 이동, 설정에서 다시 보기 흐름의 기존 테스트가 통과했다.
- 글자 크기와 화면 대비의 저장·복원 및 즉시 반영 테스트가 통과했다.
- `adb install -r`로 기존 데이터를 유지해 설치했으며 기존 포인트와 오늘의 미션 상태가 유지된 것을 확인했다.
- 에뮬레이터의 화면 크기와 글씨 배율은 점검 후 720x1280, 1.0으로 복원했다.

## 개인정보·권한 검사

- 운영 Android 매니페스트에 사진, 카메라, 연락처, 저장소, 위치 권한이 없다.
- `debug`와 `profile` 매니페스트의 인터넷 권한은 Flutter 개발 도구 연결용이며 운영 매니페스트에는 없다.
- 실제 결제·예약·행정·금융 API, 외부 공유 Intent, Firebase, 서버 연동을 사용하지 않는다.
- 연습용 PIN·환자 확인 값·사진 데이터는 SharedPreferences에 저장하거나 로그로 출력하지 않는다.
- API 키, 토큰, 비밀번호, 키스토어, 개인 PC 절대경로, 실제 개인정보가 추적 대상 소스와 문서에서 발견되지 않았다.

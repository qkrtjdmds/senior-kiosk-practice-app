# 사진 보내기 V2 설계·구현

## 목표와 V1 호환

실제 스마트폰 메신저에서 `받는 사람 확인 → 사진 버튼 → 앨범 → 사진 선택 → 미리보기 → 다시 확인 → 보내기` 순서를 안전하게 익히는 짧은 생활 연습이다. 특정 메신저 화면을 복제하지 않는다. V1 파일은 보존하고 기존 `/photo` 경로, `photo_solo_complete` 미션 ID, 완료 횟수·배지·세션 키와 `completePhotoLearning()`, `completePhotoSoloLearning()`을 그대로 재사용한다.

## 최종 흐름

1. 따라 해보기 또는 혼자 해보기 선택
2. 받을 사람과 개인·단체 채팅 확인
3. 사진 추가 버튼 선택
4. 사진 접근 권한 교육
5. 가상 앨범과 사진 선택
6. 선택 사진 크게 보기와 미리보기
7. 받을 사람·관계·사진 최종 확인
8. 네트워크 없는 가상 전송
9. 채팅방의 가상 사진 말풍선과 결과 확인
10. 잘못 보냈을 때 대처 교육과 완료 보상

## 가상 데이터

연락처는 딸 김하늘, 아들 김바다, 친구 이웃님, 가족 모임 네 개이며 전화번호와 실제 프로필 사진이 없다. 최근 사진, 가족 나들이, 음식, 꽃과 풍경 앨범과 빨간 꽃·노란 꽃·바닷가·산책길·김밥·과일·하늘·강아지 그림의 여덟 가지 도형 기반 연습 사진을 사용한다. 사진 파일, 얼굴, 위치정보와 EXIF는 사용하지 않는다.

## 권한과 사진 선택

Android 권한 창을 호출하지 않고 `선택한 사진만 허용`, `모든 사진 허용`, `허용하지 않음`의 차이를 교육한다. 선택은 세션 메모리에만 존재한다. 사진은 최대 세 장이며 선택 번호와 접근성 문구를 제공하고, 다시 누르면 취소된다. 혼자 해보기는 사진 선택 순서까지 판정한다.

## 따라 해보기와 혼자 해보기

따라 해보기는 딸 김하늘, 꽃과 풍경, 빨간 꽃 한 장, 선택한 사진만 허용을 안내한다. 혼자 해보기는 완료 횟수에 따라 다음 세 시나리오를 순환한다.

- 딸 김하늘에게 빨간 꽃 한 장
- 친구 이웃님에게 김밥·과일 두 장
- 가족 모임에 바닷가·산책길·하늘 세 장과 단체 채팅 주의

오선택은 현재 단계에 머물며 인라인 안내를 표시한다. 힌트는 감점 없이 열고 닫는다.

## 안전한 가상 전송

실제 연락처·갤러리·카메라·메신저·서버를 사용하지 않고 파일 업로드, 공유 Intent와 네트워크 요청을 만들지 않는다. 연속 전송은 Provider의 처리 잠금으로 한 번만 완료된다. 실제 삭제 기능은 제공하지 않으며 메신저별 삭제 방식이 다르고 개인정보·금융정보·신분증·비밀번호 사진을 보내지 말아야 한다는 교육만 제공한다.

## 보상과 일일 미션

따라 해보기 10점, 혼자 해보기 20점과 첫 완료 배지를 기존 Provider로 저장한다. 미션 탭에서 활성화된 기존 `photo_solo_complete`만 정상 완료 후 추가 10점을 받을 수 있다. 일반 연습은 일일 미션을 완료하지 않으며 완료 화면 재진입은 기존 세션 키로 중복 보상을 차단한다.

## 접근성·반응형

아이보리 배경, 진한 남색, 세이지색과 목록 중심 UI를 사용한다. 주요 버튼은 56dp 이상이고 모든 화면을 세로 스크롤 가능하게 구성한다. 320dp에서도 사진 격자는 2열을 유지하며 선택 번호·사진명 Semantics를 제공한다. 상단과 Android 뒤로가기는 같은 콜백을 사용한다.

## 구현 구조

- `PhotoSendProvider`: 연락처, 권한, 앨범, 선택 순서, 미리보기, 가상 전송 상태
- `PhotoSendScaffold`: SafeArea, 진행률, 뒤로가기, 하단 주 버튼
- `PhotoChoiceRow`, `PracticePhotoTile`, `PhotoInlineNotice`: 선택 목록, 2열 사진과 인라인 안내
- `PhotoSendV2StartPage`, `PhotoSendV2MissionPage`, `PhotoSendV2FlowPage`, `PhotoSendV2CompletePage`: 전체 화면 흐름

## 상태 초기화

연습을 새로 시작하면 받는 사람, 권한 선택, 앨범, 선택한 사진과 선택 순서, 미리보기, 전송 결과를 세션 메모리에서 초기화한다. 앞 단계의 선택을 바꾸면 그 선택에 의존하는 이후 단계만 초기화한다. 미션을 중도에 나가면 활성 일일 미션 ID를 해제하며, 완료 화면 직접 진입은 완료 가능한 세션인지 확인한 뒤 안전하게 시작 화면으로 돌려보낸다.

## 최종 검증 결과

- Small Phone Android 15(API 35), 360dp 기본 글씨에서 따라 해보기 전체 흐름과 혼자 해보기 첫 시나리오를 실제 완료했다.
- 따라 해보기 10점, 혼자 해보기 20점과 첫 완료 배지가 기존 저장 구조에 반영되는 것을 확인했다.
- 320dp·아주 큰 글씨에서 시작 화면과 연락처 목록을 실제 확인했고, 위젯 테스트에서 2열 사진 격자와 선택 번호가 오버플로우 없이 표시되는 것을 검증했다.
- 최신 디버그 APK를 기존 앱 데이터 위에 다시 설치해 앱 시작과 데이터 유지를 확인했다.
- 최종 APK에는 사진·연락처·카메라·저장소 권한이 없으며, 앱 저장소에 사진 파일이나 사진 선택 세션 데이터가 남지 않는 것을 확인했다.
- 전체 자동 테스트 163개, 정적 분석과 디버그 APK 빌드가 통과했다.

## 제한과 다음 단계

기기와 메신저마다 권한 문구, 앨범, 삭제 방식과 전송 화면이 다를 수 있다. 이 기능은 실제 전송을 보장하거나 특정 메신저 사용법을 복제하지 않는다. 사진 보내기 V2로 핵심 콘텐츠 7종의 V2 전환이 완료되며 다음 단계는 캐릭터 중심의 전체 앱 디자인 시스템과 홈·미션·내 정보 화면 리디자인이다.

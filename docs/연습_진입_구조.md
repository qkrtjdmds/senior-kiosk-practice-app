# 연습 진입 구조

## 목적

한걸음 디지털의 V2 콘텐츠 7종은 같은 기능을 네 가지 출처로 구분한다.

| 진입 방식 | 시나리오 판정 | 기본 보상 | 미션 추가 보상 |
|---|---|---:|---:|
| 홈 자유 연습 | 없음 | 0점 | 0점 |
| 연습하기 → 따라 해보기 | 안내 목표 적용 | 10점 | 0점 |
| 연습하기 → 혼자 해보기 | 혼자 하기 목표 적용 | 20점 | 0점 |
| 미션 → 혼자 해보기 | 혼자 하기 목표 적용 | 20점 | 10점 |

미션 여부는 혼자 하기 모드와 별개로 `DailyMissionProvider.activeMissionId`가 관리한다. 기존 콘텐츠별 모드 enum과 SharedPreferences 키는 변경하지 않는다.

## 화면 구조

- 홈: 7개 콘텐츠를 모드 선택 없이 자유 연습의 첫 실제 단계로 연결한다. 시작할 때 남아 있는 활성 미션과 임시 선택 상태를 정리한다.
- 연습하기: 평면형 7개 콘텐츠 목록에서 기존 시작 화면으로 연결한다. 목록 위에서 따라 해보기와 혼자 해보기의 안내·보상 차이를 한 번만 설명하고, 시작 화면에서 실제 모드를 고른다.
- 미션: 한국 날짜 기준으로 선정된 기존 미션 3개를 표시하며 활성 미션 ID를 설정한 뒤 해당 혼자 하기 목표 화면으로 연결한다.
- 내 정보: 기존 포인트, 완료 횟수, 배지, 최근 기록, 설정과 기록 초기화를 유지한다.

연습하기의 콘텐츠 시작 화면은 목록 위에 쌓이므로 상단 또는 시스템 뒤로가기로 연습하기 목록에 복귀한다. 직접 경로로 연 시작 화면은 기존처럼 홈을 안전한 대체 경로로 사용한다. 상세 학습 화면에서는 하단 내비게이션을 표시하지 않는다. 기존 V1 경로와 V2 세부 경로는 그대로 유지한다.

## 공통 시작 구조

- `PracticeMode`는 자유 연습, 따라 해보기, 혼자 해보기라는 공통 모드의 의미와 한글 표시명을 정의한다. 기존 콘텐츠별 enum과 저장 형식은 교체하지 않는다.
- `practice_registry.dart`는 기존 router가 보유하던 V2 Provider 인스턴스를 한곳에서 관리한다. 각 라우트는 이미 생성된 인스턴스를 `ChangeNotifierProvider.value`로 주입하므로 라우트 전환마다 중복 생성하거나 하위 화면에서 dispose하지 않는다.
- `PracticeLauncher.startFreePractice()` 역할의 공통 진입점은 실제 코드에서 `PracticeLauncher.startFree()`로 구현했다. 활성 미션을 해제하고 콘텐츠별 `startFreePractice()` 또는 `beginFreePractice()`를 호출한 다음 첫 V2 단계로 이동한다.
- 따라 해보기와 혼자 해보기는 기존 콘텐츠 시작 화면의 시작 메서드와 라우트를 그대로 사용한다. 미션 진입은 기존 `DailyMissionProvider`가 활성 미션 ID를 설정한 뒤 혼자 해보기 목표 화면으로 이동한다.

홈 자유 연습은 `/cafe/v2/menu`, `/hamburger/practice`, `/hospital/v2/step-1`, `/photo/v2/step-1`, `/train/v2/trip-type`, `/atm/v2/services`, `/civil-document/v2/categories`의 기존 첫 단계 경로를 사용한다. 별도의 테스트 전용 경로나 route extra 상태는 추가하지 않는다.

## 자유 연습

자유 연습은 각 V2 Provider의 메모리 전용 `isFreePractice` 상태로 구분한다. 기존 guided 모드를 저장하거나 완료 처리에 사용하지 않으며, 앱 재실행 뒤 이어서 수행하는 세션도 제공하지 않는다.

- 카페: 메뉴, 온도, 크기, 매장·포장, 복수 장바구니, 수량, 적립과 결제를 자유롭게 고른다.
- 햄버거: 이용 방법, 메뉴, 단품·세트, 사이드, 음료, 추가 옵션, 장바구니, 적립과 결제를 자유롭게 고른다.
- 병원: 업무 선택부터 시작해 진료 접수, 예약 확인, 수납, 서류 발급을 자유롭게 고른다.
- 기차표: 편도·왕복, 역, 날짜, 승객, 열차, 객실, 좌석과 결제를 자유롭게 고른다.
- ATM: 현금 출금, 연습용 계좌, 금액과 명세표를 자유롭게 고른다.
- 무인민원발급기: 분야, 증명서, 옵션, 부수와 결제 방식을 자유롭게 고른다.
- 사진 보내기: 받는 사람, 권한 교육 선택, 앨범과 사진 1~3장을 자유롭게 고른다.

## 안전 검증

자유 연습에서도 필수 입력, 날짜 순서, 승객·수량 제한, 매진과 예약 좌석, 잔액과 출금 단위, 연습용 PIN, 카드·현금·잔돈·출력물 회수, 최대 사진 3장과 개인정보 보호 안내는 유지한다. 목표와 다른 메뉴·계좌·금액·서류·연락처·사진을 오답으로 막는 시나리오 판정만 해제한다.

## 보상과 기록

자유 연습 완료 화면은 `자유 연습을 마쳤어요`와 `보상 없이 자유롭게 반복할 수 있는 연습이에요`를 표시한다. 기존 완료 보상 함수를 호출하지 않으므로 포인트, 따라·혼자 완료 횟수, 첫 완료 배지와 일일 미션 상태가 변하지 않는다.

최근 기록의 기존 JSON 형식은 자유 연습을 표현할 수 있지만, 저장 API가 완료 보상 처리와 결합되어 있다. 기존 데이터 마이그레이션과 보상 회귀 위험을 피하기 위해 이번 단계에서는 자유 연습을 최근 기록에 저장하지 않는다.

## 상태와 호환성

자유 연습 시작 시 콘텐츠 Provider의 임시 주문·선택·완료 상태를 초기화하고 활성 미션 ID를 해제한다. 연습하기에서 일반 콘텐츠를 선택할 때도 남은 활성 미션을 해제한 뒤 기존 시작 화면을 연다. 따라 해보기와 일반 혼자 해보기는 기존 시작 화면과 `LearningProgressProvider`의 세션 준비 메서드를 그대로 사용한다. 미션 화면은 활성 ID를 먼저 설정하고 기존 미션 시작 화면에서 중복 모드 설정으로 해제하지 않는다.

기존 SharedPreferences 키, 완료 횟수, 포인트, 배지, 최근 기록과 일일 미션 데이터는 변경하거나 마이그레이션하지 않는다.

## 검증 결과

- 홈의 7개 콘텐츠가 모드 선택 화면을 거치지 않고 각 V2 첫 단계로 이동하는 위젯 테스트를 추가했다.
- 7개 V2 Provider가 자유 연습 상태로 초기화되고, 시나리오와 다른 정상 선택을 허용하는지 확인했다.
- 사진은 최대 3장, ATM은 PIN·잔액·카드와 현금 회수, 기차는 날짜·좌석·매진, 민원 발급은 본인 확인·회수 순서 등 기존 안전 규칙을 유지한다.
- 카페 자유 연습 완료 화면에 직접 도달해도 포인트와 따라·혼자 완료 횟수가 증가하지 않는 회귀 테스트를 추가했다.
- 전체 168개 자동 테스트와 320dp·아주 큰 글씨 UI 테스트가 통과했다.
- Android Small Phone 에뮬레이터에서 최신 디버그 APK를 기존 데이터 위에 설치했다. 저장돼 있던 큰 글씨 설정으로 홈, 카페·ATM·사진 보내기 자유 연습 첫 단계를 확인하고 카페와 사진 보내기는 완료 화면까지 진행했다. 두 완료 화면의 무보상 안내를 확인했고 RenderFlex 오버플로우도 발견되지 않았다.
- 자유 연습은 기존 최근 기록 JSON과 보상 API의 결합을 건드리지 않기 위해 이번 단계에서는 최근 기록에 저장하지 않는다.

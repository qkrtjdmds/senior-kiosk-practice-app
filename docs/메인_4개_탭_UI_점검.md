# 메인 4개 탭 UI 점검

## 네 탭의 역할

- 홈: 콘텐츠를 누르면 보상 없는 자유 연습의 실제 첫 단계로 바로 이동한다. 오늘의 미션과 최근 활동은 요약만 보여준다.
- 연습하기: 콘텐츠를 고른 뒤 따라 해보기 또는 혼자 해보기를 선택한다.
- 미션: 한국 날짜 기준 오늘의 미션 3개와 `N / 3 완료`, 미션 추가 보상 상태를 보여준다.
- 내 정보: 로그인 계정이 아닌 이 기기의 연습 포인트, 완료 횟수, 배지, 최근 활동, 설정과 기록 관리를 보여준다.

## 공통 레이아웃 기준

네 탭은 아이보리 배경, 남색 글자와 아이콘, 세이지 선택 상태를 사용한다. 최상단 제목과 16~20dp 좌우 여백, 섹션 사이 간격, 얇은 테두리 목록과 SafeArea 하단 여백을 맞췄다. 캐릭터는 장식용 Semantics에서 제외하고 안내 본문보다 크게 강조하지 않는다.

홈은 브랜드 제목과 자유 연습, 미션은 날짜와 진행률, 내 정보는 로컬 기록이라는 고유 역할을 유지한다. 화면을 서로 복제하지 않고 같은 제목·여백·목록 규칙으로 한 앱처럼 보이게 한다.

## 연습하기 화면

상단에는 `연습하기` 제목, 52dp 한걸음이와 `도움을 받으며 따라 하거나, 혼자 도전해 보세요.` 안내를 배치한다. 두 모드의 설명과 보상은 콘텐츠마다 반복하지 않고 하나의 비교 영역에서 한 번만 안내한다.

- 따라 해보기: 화면 안내를 따라 한 단계씩 진행하며 완료하면 연습 포인트 10점
- 혼자 해보기: 목표를 보고 스스로 순서를 고르며 힌트를 사용할 수 있고 완료하면 연습 포인트 20점

카페 주문, 햄버거 주문, 병원 무인접수, 기차표 예매, ATM 출금, 무인민원발급기, 사진 보내기는 64dp 이상 평면형 한 열 목록으로 표시한다. 각 행은 아이콘, 이름, 짧은 설명과 이동 표시를 한 번의 버튼 Semantics로 읽는다. 아주 큰 글씨에서는 고정 높이를 사용하지 않고 자연스럽게 늘어난다.

## 진입과 뒤로가기

홈은 `PracticeLauncher.startFree`로 자유 연습에 바로 진입한다. 연습하기는 콘텐츠 시작 화면을 이전 화면 위에 열고, 시작 화면에서 따라 해보기 또는 혼자 해보기를 선택한다. 일반 연습 콘텐츠를 고르면 남아 있던 활성 미션 ID를 기존 API로 해제한다. 미션 탭에서 시작한 혼자 해보기는 활성 미션 ID를 유지한다.

연습하기에서 연 시작 화면은 상단 뒤로가기와 Android 시스템 뒤로가기 모두 연습하기 목록으로 돌아간다. 직접 경로로 연 경우에는 홈을 안전한 대체 경로로 사용한다. 실제 V2 상세 화면에서는 하단 탭을 표시하지 않는다.

## 보상과 저장 정책

| 진입 | 기본 보상 | 미션 추가 |
|---|---:|---:|
| 홈 자유 연습 | 0점 | 0점 |
| 연습하기 → 따라 해보기 | 10점 | 0점 |
| 연습하기 → 혼자 해보기 | 20점 | 0점 |
| 미션 → 혼자 해보기 | 20점 | 10점 |

Provider, 라우트 문자열, SharedPreferences 키, 완료 횟수, 배지, 최근 기록과 중복 지급 방지 정책은 변경하지 않았다. 자유 연습은 최근 기록에도 저장하지 않는다.

## 반응형과 접근성

- 360dp·보통 글씨에서 네 탭의 제목 위치, 캐릭터 크기, 첫 본문 위치와 하단 여백을 비교했다.
- 320dp·아주 큰 글씨·선명한 화면에서 모드 설명은 세로로 바뀌고 콘텐츠 행은 필요한 만큼 높아진다.
- 마지막 사진 보내기까지 스크롤할 수 있고 하단 내비게이션에 가리지 않는다.
- 하단 탭의 `연습하기`와 `내 정보`는 한글 이름이 유지되고 선택 상태는 배경, 아이콘, 글자로 함께 구분된다.
- 미션 응원 제목은 음절 중간이 아니라 `오늘도 한 걸음`과 `해볼까요?` 의미 단위로 줄바꿈하며 TalkBack에는 한 문장으로 제공한다.
- 모드 설명과 콘텐츠 행은 합쳐진 단일 Semantics로 읽어 아이콘·제목의 중복 낭독을 막는다.

실제 기기 TalkBack 전수 조작과 제조사별 글꼴·제스처 내비게이션 검증은 남아 있다.

## 검증 결과

Small Phone Android 15(API 35)에 최신 디버그 APK를 기존 데이터 위에 설치했다. 360dp·보통 글씨와 320dp·아주 큰 글씨·선명한 화면에서 홈, 연습하기, 미션, 내 정보와 하단 내비게이션을 비교했다. 7개 콘텐츠 목록 끝, 시작 화면 복귀, 상세 화면의 하단 탭 숨김을 확인했고 RenderFlex 오버플로우나 치명적 예외는 발견되지 않았다.

자동 검증은 183개 테스트, `flutter analyze`, `git diff --check`, 디버그 APK 빌드가 통과했다.

# V3 보상 적용 구현

## 선택 정책

- 획득한 칭호 중 하나를 선택하거나 `칭호 사용 안 함`으로 되돌릴 수 있다.
- 장식은 머리(모자), 얼굴(안경), 목(목도리), 옆면(가방) 슬롯을 사용한다. 서로 다른 슬롯은 동시에 착용할 수 있다.
- 획득한 홈 테마 중 하나를 선택하거나 `기본 아이보리`로 복원할 수 있다.
- 잠긴·비활성·알 수 없는 미래 보상과 `expression_celebration`은 선택할 수 없다.
- 선택은 포인트, 획득 ID·시각, pending·celebrated, 완료 횟수, 배지, 최근 기록과 미션을 변경하지 않는다.

## 저장과 실패 처리

UI는 SharedPreferences에 직접 접근하지 않는다. `RewardRepository`가 선택값을 검증하고 저장하며, `RewardProgressProvider`가 빠른 요청을 순서대로 처리한다. 저장 성공 뒤에만 화면 상태를 갱신하고 실패하면 이전 저장 상태를 복원한 뒤 인라인 안내를 표시한다. 앱 재실행 시 선택값을 다시 불러온다.

기록 초기화는 포인트 보상 획득 상태와 선택한 칭호·장식·홈 테마를 함께 삭제한다. 글자 크기, 대비, 온보딩과 일반 설정은 유지한다.

## CustomPainter 레이어

한걸음이의 기본 몸체와 새싹을 유지하고 코드 기반 레이어로 가방, 모자, 안경, 목도리를 그린다. 모자는 새싹과 얼굴을 가리지 않고, 안경은 눈과 표정을 보존하며, 목도리는 입 아래에 배치한다. 가방은 64dp 미만 캐릭터에서 생략해 복잡도를 낮춘다. 외부 이미지와 타사 에셋은 사용하지 않는다.

선택 장식은 홈 환영 영역과 `나의 보상` 미리보기에 적용한다. 온보딩과 작은 학습 안내 캐릭터는 브랜드 기본 모습과 공간을 보존하기 위해 장식 없이 유지한다.

## 홈 테마 범위

테마는 홈 배경, 환영 영역의 연한 배경과 보상 보조색에만 적용한다. 앱 ThemeData, 학습·결제 화면, 다른 탭, 버튼 의미색과 경고색은 변경하지 않는다. 선명한 화면에서는 기존 고대비 색상을 우선한다.

## 접근성과 반응형

보상 행은 이름·설명·기준·획득·적용 상태를 한 번에 읽고, 선택 가능한 행에만 button과 selected Semantics를 제공한다. 미리보기 캐릭터는 그림 낭독을 제외하고 선택한 칭호·테마·장식 이름을 한 번만 제공한다. 320dp와 아주 큰 글씨에서는 미리보기를 세로 배치하고 전체 목록을 스크롤한다.

## 제한

특별 축하 표현과 pending 보상 소비는 다음 `V3 보상 획득 축하 안내` 작업에서 구현한다. 앱은 무료이며 인앱결제, 구독, 광고, 포인트 판매·차감·환전·전송 기능이 없다.

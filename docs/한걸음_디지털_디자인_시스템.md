# 한걸음 디지털 디자인 시스템

## 브랜드 원칙

한걸음 디지털은 어르신을 어린아이처럼 대하지 않고, 실제 디지털 기기에 도전할 용기를 주는 연습 앱이다. 핵심 문구는 **“천천히, 한 걸음씩 연습해요”**이며 친절함, 존중, 차분함과 안정감을 우선한다. 특정 교육 앱의 캐릭터나 색상, 문구, 레이아웃을 복제하지 않는다.

## 디자인 토큰

- 배경 `#F7F3EA`, 표면 `#FFFDF8`
- 주요 행동 `#21324A`, 세이지 `#71866F`, 세이지 배경 `#E5ECE2`
- 크림 `#F2E8D8`, 본문 `#202A35`, 보조 본문 `#58616B`
- 기본 좌우 여백 20dp, 340dp 이하 16dp
- 간격 4·8·12·16·20·24·32dp
- 기본 모서리 16dp, 작은 모서리 12dp, 강조 영역 24dp
- 주요 버튼 56dp 이상, 큰 선택 행 72dp 이상, 터치 영역 48×48dp 이상

토큰은 `lib/app/app_theme.dart`의 `AppColors`, `AppSpacing`, `AppRadius`, `AppSizes`에서 관리한다. 선명한 화면에서는 배경과 본문·테두리 대비를 높인다.

## 타이포그래피와 접근성

기존 글자 크기 Provider의 보통·크게·아주 크게 배율을 유지한다. 긴 문구는 줄바꿈하고, 320dp 화면에서는 한 열 목록을 사용한다. 정보 상태는 색상뿐 아니라 아이콘과 한글 문구를 함께 사용한다.

## 한걸음이 캐릭터

한걸음이는 새싹과 작은 발걸음을 상징하는 코드 기반 캐릭터다. 둥근 세이지 몸체, 남색 윤곽, 크림 포인트를 사용한다. 환영·안내·응원·다시 시도·완료·빈 기록·도움 상태를 지원하며, 장식 이미지는 접근성 트리에서 제외하고 의미는 별도 텍스트로 제공한다.

사용 위치는 시작 안내, 홈 상단, 연습하기 안내, 미션 응원, 내 정보의 안내·빈 상태로 제한한다. 실제 키오스크 메뉴, ATM 키패드, 좌석도나 출력 흐름을 가리지 않는다.

## 앱 아이콘과 네이티브 시작 화면

앱 아이콘은 한걸음이의 새싹, 둥근 얼굴과 미소를 굵고 단순한 형태로 재구성한다. 연한 세이지 배경, 아이보리 얼굴, 남색 윤곽을 사용하며 글자는 넣지 않는다. legacy icon, adaptive foreground/background와 Android 13 이상 monochrome icon을 제공한다.

네이티브 시작 화면은 Android 11 이하와 12 이상 모두 아이보리 배경과 같은 한걸음이 심볼을 사용한다. 시스템이 어두운 모드여도 검은 화면으로 전환되지 않으며, 로딩 문구나 인위적인 지연 없이 Flutter 온보딩 또는 홈으로 이어진다. 원본과 재생성 방법은 `docs/앱_아이콘_및_시작_화면.md`에 기록한다.

## 시작 안내

첫 실행 또는 안내 미완료 상태에서 앱 소개와 글자 크기 미리보기를 제공한다. 완료 상태는 `onboarding_completed_v1`에 저장하며 연습 기록 초기화 대상에서 제외한다. 설정의 **시작 안내 다시 보기**로 다시 열 수 있다. 기존 딥링크와 상세 라우트는 시작 안내로 차단하지 않는다.

## 주요 화면

- 홈: 캐릭터 환영, 오늘의 미션 진행률, 7개 자유 연습 한 열 목록, 최근 활동
- 연습하기: 7개 콘텐츠와 기존 따라 해보기·혼자 해보기 진입
- 미션: 작은 캐릭터 안내, 날짜·완료 수·진행 바 통합 요약, 평면형 세 미션과 완료·보상 상태
- 내 정보: 포인트, 완료 횟수, 배지, 최근 기록과 설정 진입
- 설정: 글자 크기, 대비, 시작 안내 다시 보기, 기록 초기화
- 하단 탭: 홈·연습하기·미션·내 정보를 아이콘과 한글로 항상 표시

## 공통 위젯

`CharacterMessage`는 캐릭터 안내를, `AppListRow`는 콘텐츠 목록을 통일한다. `PageScaffold`는 반응형 좌우 여백과 안전한 뒤로가기를 제공한다. 버튼과 카드 모양은 ThemeData에서 중앙 관리한다.

## 기존 사용자와 저장 데이터

포인트, 배지, 최근 기록, 오늘의 미션, 글자 크기와 화면 대비, 7개 V2 Provider 상태 및 기존 SharedPreferences 키를 변경하지 않는다. 기록 초기화는 연습 기록만 지우고 온보딩·접근성 설정을 유지한다. 자유 연습은 0점이며 최근 기록에 저장하지 않는다.

## 앱 외부와 실제 연습 내부의 구분

홈·탭·설정은 아이보리·남색·세이지 브랜드를 사용한다. 카페 메뉴판, 병원 업무, 기차 좌석도, ATM 키패드, 민원 출력, 사진 채팅·갤러리 등 내부 연습 화면은 실제 기기 적응을 위한 고유 구조를 유지한다.

## 연습 내부 공통 규칙

- `PracticeAppBar`: 68dp 높이, 48dp 이상 뒤로가기, 최대 두 줄 제목, 얇은 구분선
- `PracticeProgressHeader`: 현재 단계·전체 단계·단계 이름과 접근성 진행률
- `PracticeModeBadge`: 자유 연습·따라 해보기·혼자 해보기·오늘의 미션을 글자와 아이콘으로 표시
- `PracticeInlineNotice`: 일반·성공·주의 안내를 화면 안에서 표시하며 검은 Snackbar를 사용하지 않음
- `PracticeBottomActions`: SafeArea, 좌우 공통 여백, 56dp 이상 주요 버튼
- `PracticeCompletionHeader`와 `PracticeRewardSummary`: 작은 축하 캐릭터, 완료 문구, 모드 및 보상 안내

공통 위젯은 화면 배치만 담당한다. 콘텐츠 Provider의 시나리오 판정, 민감 상태 정리, 가격 계산, 보상 지급, 미션 ID와 라우팅은 소유하지 않는다. 시스템 뒤로가기와 상단 뒤로가기는 각 화면이 전달한 같은 콜백을 실행한다.

### 고유 UI 보존

- 카페·햄버거: 메뉴판, 옵션, 복수 장바구니와 영수증
- 병원: 네 업무와 반응형 숫자 키패드
- 기차표: 왕복 여정, 열차 목록과 좌석도
- ATM: PIN 키패드와 카드·현금 회수 순서
- 무인민원발급기: 옵션, 결제, 출력과 회수 제한
- 사진 보내기: 가상 연락처, 채팅, 사진 격자와 선택 순서

본문 목록은 고정 하단 동작 영역에 가리지 않도록 충분한 하단 스크롤 여백을 둔다. 320dp·아주 큰 글씨에서는 긴 문구를 줄바꿈하고, 진행 문구는 의미를 유지한 채 말줄임하며, 고유 조작부의 Semantics를 보존한다.

## Small Phone 실제 검증

- Android 15(API 35) `Small_Phone`에서 기존 앱 데이터를 유지한 채 디버그 APK를 설치했다.
- 360dp·보통 글씨와 320dp·아주 큰 글씨·선명한 화면에서 시작 안내, 홈, 연습하기, 미션, 내 정보, 설정을 확인했다.
- 기존 포인트 130점, 완료 횟수, 배지, 최근 기록, 오늘의 미션과 접근성 설정이 APK 재설치 뒤에도 유지됐다.
- 시작 안내의 고정 캐릭터 크기와 큰 제목이 좁은 화면의 세로 공간을 과도하게 차지하던 문제를 수정했다. 캐릭터, 제목 단계와 간격을 줄이고 전체 화면 스크롤을 유지해 핵심 `연습 시작하기` 버튼이 첫 화면에 보이도록 했다.
- 하단 탭은 320dp·아주 큰 글씨에서도 네 아이콘과 한글 이름이 겹치지 않았으며, 각 탭 본문과 목록은 세로 스크롤로 끝까지 접근할 수 있었다.
- 선명한 화면에서도 배경, 테두리, 선택 상태와 주요 버튼의 대비가 유지됐다.
- 앱 셸 리디자인 당시 자동 검증은 172개 테스트가 통과했다. 연습 내부 공통 UI 통합 후에는 174개, 출시 전 접근성·시스템 뒤로가기 회귀 테스트 보완 후에는 175개 테스트가 통과했다. `flutter analyze`, 공백 검사와 디버그 APK 빌드도 모두 통과했다.

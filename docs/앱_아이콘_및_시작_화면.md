# 앱 아이콘 및 시작 화면

## 디자인 의도

앱 아이콘은 코드 기반 한걸음이 캐릭터의 둥근 얼굴, 두 장의 새싹, 남색 눈과 미소를 단순화했다. 작은 런처 아이콘에서도 표정이 구분되도록 선을 굵게 하고 글자는 사용하지 않았다. 얼굴과 새싹은 Android 원형·둥근 사각형·squircle 마스크의 중앙 안전 영역 안에 배치했다.

사용 색상은 기존 디자인 토큰과 같다.

- 아이보리 `#F7F3EA`
- 남색 `#21324A`
- 세이지 `#71866F`
- 연한 세이지 `#E5ECE2`

외부 이미지와 브랜드 에셋은 사용하지 않았다. 모든 원본은 프로젝트 안의 SVG에서 생성한다.

## 원본 에셋

`assets/branding/`에 다음 파일을 보관한다.

- `app_icon_source.svg`: 전체 색상 아이콘 벡터 원본
- `app_icon_foreground_source.svg`: adaptive icon 및 Splash용 투명 전경 원본
- `app_icon_monochrome_source.svg`: Android 13 이상 테마 아이콘용 단색 원본
- `app_icon_1024.png`: 1024×1024 고해상도 아이콘
- `app_icon_foreground_1024.png`: 1024×1024 투명 전경
- `app_icon_monochrome_1024.png`: 1024×1024 투명 단색 전경
- `app_icon_play_512.png`: Google Play 등록용 512×512 미리보기
- `splash_mark.png`: 768×768 네이티브 시작 화면 심볼

## Android 아이콘 구조

- Android 7 이하 및 legacy launcher: 밀도별 `mipmap-*/ic_launcher.png`
- Android 8 이상 adaptive icon: `mipmap-anydpi-v26/ic_launcher.xml`
- adaptive background: `#E5ECE2`
- adaptive foreground: 밀도별 `drawable-*/ic_launcher_foreground.png`
- Android 13 이상 themed icon: 밀도별 `drawable-*/ic_launcher_monochrome.png`

패키지명과 애플리케이션 ID는 변경하지 않았다.

## 네이티브 시작 화면

- Android 11 이하: 아이보리 배경과 중앙 `splash.png`를 `launch_background.xml`에서 표시한다.
- Android 12 이상: 시스템 SplashScreen의 배경, 아이콘 배경과 `android12splash.png`를 사용한다.
- 밝은 모드와 어두운 모드 모두 아이보리 배경을 사용한다.
- `NormalTheme`도 아이보리로 맞춰 Flutter 첫 프레임 전 검은 화면이나 흰색 번쩍임을 줄였다.
- 로딩 문구, 진행률, 인위적인 지연은 추가하지 않았다.

## 재생성 방법

벡터 원본을 수정한 경우 headless Chrome의 `--screenshot` 옵션으로 다음 PNG를 다시 만든다.

1. `app_icon_source.svg`에서 1024px 및 512px PNG 생성
2. 투명 배경 옵션 `--default-background-color=00000000`으로 foreground, monochrome, Splash PNG 생성
3. 아래 명령 실행

```bash
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

Windows에서 개발자 모드가 꺼져 `dart run`이 플러그인 심볼릭 링크 검사에서 중단되면 개발자 모드를 활성화한다. 시스템 설정을 바꾸지 않고 생성기만 실행해야 할 때는 `.dart_tool/package_config.json`을 지정해 각 패키지의 `bin` 진입 파일을 직접 실행할 수 있다. 이번 생성에는 다음 PowerShell 명령을 사용했다.

```powershell
dart --packages=.dart_tool/package_config.json "$env:LOCALAPPDATA\Pub\Cache\hosted\pub.dev\flutter_launcher_icons-0.14.4\bin\flutter_launcher_icons.dart"
dart --packages=.dart_tool/package_config.json "$env:LOCALAPPDATA\Pub\Cache\hosted\pub.dev\flutter_native_splash-2.4.7\bin\create.dart"
```

생성 후 야간 모드의 `NormalTheme`이 아이보리 배경을 유지하는지 확인한다. 패키지를 다시 실행하면 생성 파일이 갱신될 수 있으므로 `git diff` 검토가 필요하다.

## 검증

- 원본 PNG 크기와 투명도 형식을 확인했다.
- Android 이미지 리소스 전체 용량은 약 456KB이다.
- 원형·둥근 사각형 adaptive mask의 중앙 안전 영역 안에 얼굴과 새싹이 위치한다.
- Small Phone Android 15(API 35)에 `adb install -r`로 설치해 기존 데이터를 유지했다. 설치 전후의 포인트는 130점으로 같았다.
- 360dp 기본 화면과 320dp 화면에서 런처 아이콘, Android 12 이상 Splash, Flutter 홈 전환을 확인했다.
- 시스템 야간 모드에서도 아이보리 Splash 배경과 한걸음이 심볼이 유지되어 검은색 또는 흰색 번쩍임이 나타나지 않았다.
- 런처의 원형 마스크에서 얼굴 윤곽과 새싹이 잘리지 않고 앱 이름 `한걸음 디지털`이 올바르게 연결되는 것을 확인했다.
- `flutter analyze` 무경고, 전체 175개 테스트 통과, 디버그 APK 빌드 성공과 logcat의 치명적 예외·RenderFlex 오류 없음까지 확인했다.

## 남은 제한 사항

- 실제 제조사 런처의 squircle, 원형, 테마 아이콘 색상은 실기기에서 추가 확인이 필요하다.
- Google Play Console에 업로드한 뒤 스토어 측 512px 리샘플링 결과를 확인해야 한다.
- Android 11 이하 실제 기기에서 legacy Splash 전환을 추가 확인해야 한다.

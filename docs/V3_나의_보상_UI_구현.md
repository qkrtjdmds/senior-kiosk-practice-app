# V3 나의 보상 UI 구현

## 1. 범위

기존 누적 포인트 보상 데이터를 사용자가 확인할 수 있도록 홈, 내 정보와 전용 `나의 보상` 화면에 연결했다. 앱은 광고·인앱결제·구독 없이 무료로 제공하는 구조이며 연습 포인트는 현금 가치가 없다. 포인트는 구매·환불·환전·전송할 수 없고 보상을 받아도 차감되지 않는다. 기존 7개 콘텐츠와 접근성 기능은 로그인 없이 무료로 유지한다.

이번 단계는 읽기 전용 UI다. 칭호·한걸음이 장식·홈 테마 선택, 실제 `CustomPainter` 장식과 테마 적용, 보상 획득 축하 화면은 구현하지 않는다.

## 2. 상태 관리

`RewardProgressProvider`는 `RewardRepository`와 기존 `LearningProgressProvider`를 결합한다.

- 활성 보상과 획득·미획득 목록
- 현재 포인트와 획득 수
- 저장된 적용 중 상태
- 현재 성장 단계
- 다음 보상 기준과 같은 기준의 복수 보상
- 다음 기준까지 필요한 포인트와 진행률
- 포인트·기록 초기화 뒤 저장 상태 재복원

자동 해제와 소급 지급은 계속 `RewardUnlockService`가 담당한다. UI Provider는 SharedPreferences를 직접 읽거나 포인트를 지급하지 않고 선택 ID·축하 완료 ID도 저장하지 않는다.

## 3. 화면 구조

### 홈 요약

현재 연습 포인트, 현재 성장 단계, 다음 보상, 필요한 포인트와 진행 바를 낮은 요약 영역에 표시한다. 같은 기준에서 둘 이상의 보상이 열리면 첫 보상과 추가 개수를 하나의 목표로 보여 준다. 모든 활성 보상을 획득하면 완료 문구와 100% 진행률을 표시한다. `나의 보상 보기`는 전용 화면으로 이동한다.

### 내 정보 요약

기존 배지와 별도인 `나의 보상` 영역을 성장 요약 다음에 배치한다. 현재 포인트·획득한 활성 보상 수·성장 단계·다음 보상을 요약하고 `전체 보상 보기`로 이동한다. 콘텐츠별 완료 현황, 기존 배지, 최근 활동, 설정과 기록 관리는 그대로 유지한다.

### 나의 보상

`/rewards` 라우트는 상단·시스템 뒤로가기를 동일하게 처리한다. 성장 요약, 비금전성 포인트 안내, 보상 종류, 전체 활성 보상 목록 순서로 구성한다. 목록은 `requiredPoints`, `sortOrder` 순서이며 같은 기준의 보상도 각각 표시한다.

각 행은 이름, 설명, 누적 기준, 종류와 다음 상태 중 하나를 제공한다.

- `획득`
- `적용 중`
- `N점 더 필요`

비활성 보상과 알 수 없는 미래 ID는 목록에서 제외한다. 획득한 칭호·장식·홈 테마는 선택할 수 있고 잠긴 보상과 특별 축하 표현에는 탭 동작을 제공하지 않는다.

## 4. Pending 보존

홈·내 정보·보상 화면을 열어도 `celebratedRewardIds`를 변경하지 않는다. 획득 ID와 축하 완료 ID의 차이는 앱 재실행 뒤에도 유지되며 다음 `보상 획득 축하 안내` 단계에서만 소비한다.

## 5. 기록 초기화

기존 기록 초기화는 포인트, 완료 횟수, 배지, 최근 기록, 미션과 함께 획득 보상·시각·적용 상태·pending 축하 상태를 삭제한다. schema와 완료 revision, 글자 크기, 화면 대비, 온보딩과 일반 설정은 유지한다. 확인 대화상자에는 획득한 칭호·꾸미기·홈 테마가 삭제된다는 내용을 명시한다. 초기화 직후 세 화면은 0점·미획득 상태로 갱신된다.

## 6. 접근성과 반응형

- 진행률은 현재 점수, 다음 기준과 남은 점수를 Semantics로 제공한다.
- 각 보상 행은 이름·설명·종류·기준·상태를 하나의 Semantics 영역으로 읽는다.
- 획득 여부는 색상뿐 아니라 문구와 아이콘 명암으로 구분한다.
- 긴 보상 이름과 상태 배지는 줄바꿈 가능한 구조다.
- 이동 버튼은 최소 56dp, 목록 행은 최소 72dp다.
- 320dp·아주 큰 글씨·선명한 화면에서도 세로 배치와 전체 스크롤을 사용한다.
- 마지막 보상은 하단 시스템 영역에 가리지 않는다.

## 7. 검증과 제한

0점, 기준 직전·정확한 기준, 160점 소급 사용자, 같은 기준 복수 보상, 5,000점 전체 획득, 비활성·미래 ID, 적용 중 상태, pending 재실행 보존, 기록 초기화, 홈·내 정보 라우팅과 320dp 큰 글씨를 자동 테스트한다.

Small Phone Android 15/API 35에 최신 디버그 APK를 기존 데이터 유지 방식으로 설치했다. 저장된 0점·아주 큰 글씨 상태에서 홈 요약, 내 정보의 `획득한 보상 0 / 12`, 전체 보상 목록, 스크롤과 뒤로가기를 확인했고 360dp와 320dp 모두 RenderFlex 및 치명적 예외가 없었다.

칭호·장식·홈 테마 선택 저장과 홈·미리보기 렌더링을 구현했다. 보상 획득 축하 안내와 pending 소비는 다음 작업이며, 실제 기기의 TalkBack 전수 조작은 별도 확인이 필요하다.

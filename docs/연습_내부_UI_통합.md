# 연습 내부 UI 통합

## 목적

앱 셸과 7개 V2 연습이 하나의 서비스처럼 보이도록 상단 바, 진행 표시, 인라인 안내와 하단 동작 영역을 통일한다. 실제 기기 적응에 필요한 콘텐츠별 조작 구조와 모든 학습·보상 로직은 유지한다.

## 공통 구조

1. 68dp `PracticeAppBar`에서 제목과 48dp 이상 뒤로가기를 제공한다.
2. 단계 화면은 현재 단계, 전체 단계, 단계 이름과 진행 바를 표시한다.
3. 연습 모드는 색상만 사용하지 않고 `자유 연습`, `따라 해보기`, `혼자 해보기`, `오늘의 미션` 문구로 구분한다.
4. 안내와 힌트는 화면 안의 세이지 계열 영역에 짧은 문장으로 표시한다.
5. 주요 동작은 SafeArea가 적용된 `PracticeBottomActions`에 배치한다.
6. 완료 화면은 축하 상태, 모드, 고유 결과 요약, 보상과 이동 동작 순서를 따른다.

## 뒤로가기 정책

공통 위젯은 경로를 직접 결정하지 않는다. 상단 버튼과 Android 시스템 뒤로가기는 콘텐츠 페이지가 전달한 같은 콜백을 사용한다. 따라서 ATM PIN 삭제, 결제·출력 우회 방지, 이후 단계 초기화, 미션 중도 이탈 정리 같은 기존 안전 동작이 유지된다.

## 콘텐츠별 유지 영역

- 카페: 가로 카테고리, 2열 메뉴, 옵션, 장바구니, 적립·결제 목록, 영수증
- 햄버거: 메뉴와 세트 구성, 사이드·음료, 복수 장바구니, 영수증
- 병원: 진료 접수·예약 확인·진료비 수납·서류 발급과 공통 숫자 키패드
- 기차표: 편도·왕복, 역 검색, 열차, 객실, 좌석도와 모바일 승차권
- ATM: 카드, PIN, 계좌, 금액, 카드·현금 회수와 명세
- 무인민원발급기: 증명서·옵션·부수, 가상 본인 확인, 결제, 출력·회수
- 사진 보내기: 가상 연락처, 권한 교육, 사진 격자, 최대 3장 선택과 가상 채팅

이 영역을 공통 카드나 일반 목록으로 바꾸지 않는다.

## 접근성

- 주요 버튼 56dp 이상, 아이콘 터치 영역 48×48dp 이상
- 진행률 Semantics 값 제공
- 긴 제목은 최대 두 줄, 요약 줄은 한 줄 말줄임
- 선택 상태는 색상과 함께 아이콘·문구로 전달
- 고대비 테마와 기존 글자 크기 배율 사용
- 320dp·아주 큰 글씨에서도 세로 스크롤과 SafeArea로 모든 동작에 접근
- 무인민원발급기 목록은 고정 하단 버튼을 고려해 180dp 하단 여백 유지

## 로직 경계

Provider, 라우팅, 시나리오, 가상 가격, 미션 ID, SharedPreferences 키와 보상 정책은 변경하지 않는다.

| 진입 | 기본 보상 | 미션 추가 |
|---|---:|---:|
| 홈 자유 연습 | 0점 | 0점 |
| 따라 하기 | 10점 | 0점 |
| 혼자 하기 | 20점 | 0점 |
| 오늘의 미션 | 20점 | 10점 |

자유 연습은 완료 횟수·배지·최근 기록을 변경하지 않으며, 완료 화면 재진입과 빠른 중복 요청에 대한 기존 방지를 유지한다.

## 검증

- 공통 위젯은 320dp·아주 큰 글씨·선명한 화면에서 RenderFlex overflow 없이 표시되는 위젯 테스트를 둔다.
- 기존 콘텐츠별 회귀 테스트를 삭제하거나 약화하지 않는다.
- 무인민원발급기 카드 회수와 출력 단계는 스크롤 후 실제 터치 가능한 상태를 검증한다.
- 최종적으로 전체 테스트, 정적 분석, 공백 검사와 디버그 APK 빌드를 실행한다.

### Small Phone 결과

- Android 15 `Small_Phone`에 기존 데이터를 지우지 않고 최종 디버그 APK를 재설치했다.
- 360dp·보통 글씨에서 홈과 설정, 카페 V2 상단·메뉴판·진행 표시를 확인했다.
- 320dp·아주 큰 글씨에서 카페 2열 메뉴, 가로 카테고리, 햄버거 선택 화면과 고정 하단 버튼을 확인했다.
- 긴 제목, 장바구니 배지, 단계 문구와 하단 동작에서 RenderFlex overflow나 가림이 없었다.
- Android 시스템 뒤로가기는 콘텐츠가 전달한 안전한 뒤로가기와 같은 결과를 냈으며 앱 예외가 없었다.
- 전체 174개 테스트, 정적 분석, 공백 검사와 디버그 APK 빌드가 통과했다.

## 남은 작업

- 출시 전 전체 회귀·문구 점검
- TalkBack 실제 기기 읽기 순서 점검
- 다양한 Android 제조사 글꼴 배율에서 완료 화면 확인
- 사용자 관찰을 통한 단계 이름과 안내 문구 개선
